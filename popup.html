Kumpulkan URL localhost OAuth dari banyak akun Google

Terkumpul: 0 URL
Cara pakai:
1. Semua akun Google sudah login di browser ini
2. Klik "Buka Link OAuth" → pilih akun → centang izin → Continue
3. URL localhost:8080/?code=... otomatis tersimpan
4. Ulangi untuk tiap akun, lalu "Simpan ke File"
